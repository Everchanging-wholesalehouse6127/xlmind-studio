# Getting started with XLMind Studio

From download to your first result in a few minutes.

> XLMind Studio is a Windows desktop add-in for Microsoft Excel. It requires **64-bit desktop Microsoft Excel on Windows**. See [installation.md](installation.md) for the full requirements.

## 1. Download

Download the installer from the official download page:

→ **<https://xlmindstudio.com/en/download?utm_source=github&utm_medium=referral&utm_campaign=github_public_repo&utm_content=getting_started_download>**

This is the only canonical source. XLMind Studio is not distributed through GitHub Releases, app stores, mirrors or third-party download sites.

Optional but recommended: before installing, verify the installer’s digital signature and SHA-256 checksum — see [security.md](security.md).

## 2. Install

1. Close Microsoft Excel if it is open.
2. Run the downloaded installer and follow the steps.
3. Depending on your Windows and company policies, you may be asked for administrator permission. On a managed corporate device this may need IT approval.

If Windows shows a SmartScreen notice, see [troubleshooting.md](troubleshooting.md) — it explains what the notice means and how to confirm the publisher.

## 3. Open Microsoft Excel

Start Excel and open a workbook. Two new tabs appear on the ribbon:

| Ribbon tab | What lives there |
|---|---|
| **XLMind Data** | Quick, Clean, Extract, Text & Numbers, Date, Codes & Output, Practical |
| **XLMind Plus** | Combine & Get, Summarize & Prepare, Compare & Check, Data Profile, Formula Audit, Dashboard, Color Tools |

If the tabs are not visible, see [troubleshooting.md](troubleshooting.md).

## 4. Start the free trial

The free trial runs for **7 days** with **all features available**, and the period starts with your first successful trial activation.

Use the **Activate** button in the **Account** group on either ribbon tab to start the trial, or to enter a license code if you have already bought one.

The trial does not turn into a paid license by itself — no charge is made when it ends.

## 5. Run your first tool

A good first run, on a copy of a messy export:

1. Select the data range or click inside your table.
2. Go to **XLMind Data**.
3. In the **Clean** group, try **Trim**, **Clean** or **Fix Broken Characters**.
4. Check the result. If it is not what you wanted, use **Undo Last** in the **Quick** group.

Then try one of these, depending on what you do most:

| If you want to… | Go to | Try |
|---|---|---|
| Understand a table you were just sent | **XLMind Plus › Data Profile** | **Data Profile** |
| Check two lists against each other | **XLMind Plus › Compare & Check** | **Compare Two Lists** |
| Find where a formula breaks | **XLMind Plus › Formula Audit** | **Highlight Error Cells**, **Formula Map Summary** |
| Combine monthly sheets | **XLMind Plus › Combine & Get** | **Append Worksheets** |
| Build a reporting panel | **XLMind Plus › Dashboard** | **Create Dashboard** |

## 6. Work safely while you learn

- Try new tools on a **copy** of your workbook first.
- **Undo Last** reverses the most recent XLMind Studio operation.
- Save before running a tool that rewrites a large range.
