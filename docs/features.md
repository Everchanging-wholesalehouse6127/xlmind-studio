## XLMind Data — get the data into shape

### [Quick](https://xlmindstudio.com/en/features#hizli) — 2 tools
Everyday quick actions that sit at the front of the ribbon: undo the last XLMind Studio operation, and auto-fit a range in one step. **Benefit:** experiment freely, because one click puts the sheet back.

### [Clean](https://xlmindstudio.com/en/features#temizle) — 8 tools
Turn a raw export into a usable table: trim and clean stray whitespace, repair broken characters, clean up header rows, delete blank rows, unmerge cells and fill the gaps. **Benefit:** the fifteen-minute tidy-up before real work becomes a few clicks.

### [Extract](https://xlmindstudio.com/en/features#ayikla) — 9 tools
Pull structured values out of unstructured text — extract by pattern, quick extract, and split one column into several. **Benefit:** no nested formula chains just to separate a code from a description.

### [Text & Numbers](https://xlmindstudio.com/en/features#metin-sayi) — 10 tools
Reshape text and repair numbers: change case, add prefixes and suffixes, remove duplicates inside a cell, convert text to real numbers, fix apostrophe numbers and leading zeros, convert formulas to values. **Benefit:** numbers that finally sum, and text that finally matches.

### [Date](https://xlmindstudio.com/en/features#tarih) — 5 tools
Repair dates that arrived as text, check a date column for problems, and build new date values. **Benefit:** date columns you can actually sort, filter and pivot on.

### [Codes & Output](https://xlmindstudio.com/en/features#kodlar-cikti) — 3 tools
Mask sensitive values before sharing a file, write numbers out as words, and colour alternating rows. **Benefit:** files that are safe to send and easy to read.

### [Practical](https://xlmindstudio.com/en/features#pratik) — 7 tools
Small daily helpers — image validation, barcode and QR code creation and other everyday shortcuts. **Benefit:** the odd jobs that normally interrupt your day stop interrupting it.

## XLMind Plus — combine, verify, report

### [Combine & Get](https://xlmindstudio.com/en/features#birlestir-getir) — 4 tools
Append worksheets, append selected tables, look values up from another table by key, and run multi-column lookups. **Benefit:** twelve monthly sheets become one dataset without copy-paste.

### [Summarize & Prepare](https://xlmindstudio.com/en/features#ozet-hazirla) — 3 tools
Group by, unpivot columns and split data into the shape reporting needs. **Benefit:** a cross-tab you were sent becomes a table a pivot can actually use.

### [Compare & Check](https://xlmindstudio.com/en/features#karsilastir-kontrol) — 6 tools
Compare two lists, compare rows, highlight duplicates and unique values, extract a unique list and add duplicate counts. **Benefit:** you find the mismatch before someone else does.

### [Data Profile](https://xlmindstudio.com/en/features#profil) — 1 tool
A single page describing the health and structure of your table — what is in each column, what is missing, what looks wrong. **Benefit:** you understand an unfamiliar file before you build anything on top of it.

### [Formula Audit](https://xlmindstudio.com/en/features#formul-denetimi) — 24 tools
The deepest group in the product. Highlight formula cells, error cells and formulas containing external links, produce a formula map summary of the workbook, and run advanced audits. **Benefit:** you can take responsibility for a model you did not build.

### [Color Tools](https://xlmindstudio.com/en/features#renk-araclari) — 2 tools
Count and sum by cell colour. **Benefit:** colour-coded sheets stop being a dead end.

### [Dashboards & Reports](https://xlmindstudio.com/en/features#dashboard) — 14 tools
Build a panel from ready-made layouts — Executive, Sales, HR and Finance — with **Create Dashboard** and **Create Report**. **Benefit:** a presentable report without rebuilding the layout each period.

### [KPI Cards](https://xlmindstudio.com/en/features#kpi-kartlari) — 13 tools
Live cards, in a choice of layouts, that show a single metric at a glance and refresh with the data behind them. **Benefit:** the headline number is visible without reading the table.

### [Charts](https://xlmindstudio.com/en/features#grafikler) — 27 tools
Data-bound chart types that stay live rather than being pasted pictures. **Benefit:** the visual updates when the data does.

### [Maps](https://xlmindstudio.com/en/features#haritalar) — 15 tools
Geographic maps that shade regions by value. **Benefit:** regional performance reads at a glance.

## Where the tools run

Every tool works on the workbook that is already open in Excel — usually on the range or table you have selected. There is no export step, no separate application and no cloud round trip: your Excel data stays on your computer for XLMind Studio’s local processing.
