# Changelog

Public release notes for **XLMind Studio**, the Windows desktop add-in for Microsoft Excel.

> **Where releases live.** XLMind Studio installers are distributed only from the [official download page](https://xlmindstudio.com/en/download?utm_source=github&utm_medium=referral&utm_campaign=github_public_repo&utm_content=changelog_download). They are not published as GitHub Releases.
>
> **Always-current release data.** The current version number, publisher details and the SHA-256 checksum of the current installer are maintained on the official security page rather than duplicated here, so that they never go stale:
> [English](https://xlmindstudio.com/en/security) · [Türkçe](https://xlmindstudio.com/tr/guvenlik)

## How to read this file

- Entries are listed newest first.
- Only user-visible changes are recorded here: new tools, changed behaviour, fixes and compatibility notes.
- Internal implementation detail is not published, because XLMind Studio is proprietary software and its source code is not part of this repository.

## Current public release

**1.0.19** — the version published on the official website when this changelog was created. The exact installer file name and its SHA-256 checksum for this release are listed on the [security page](https://xlmindstudio.com/en/security).

Detailed public release notes will be added here from the next release onward.

## Earlier releases

Per-version notes for releases before 1.0.19 were not published in this format. If you need to know whether a specific fix or tool is included in the build you are running, contact <support@xlmindstudio.com> with your XLMind Studio version.

## Update policy

- Check for updates from inside the product, or use the update link provided to you.
- Back up important workbooks before installing an update.
- Update eligibility and support duration are described in the [Update & Support Policy](https://xlmindstudio.com/en/updates-and-support).
