Thanks for using **XLMind Studio** — a Windows desktop add-in that adds 153 productivity tools to Microsoft Excel.

This page explains where to get help, and what belongs in a GitHub issue versus a private support request.

## Official support channels

| Channel | Use it for | Link |
|---|---|---|
| **Support page and contact form** | Anything account-related: licensing, activation, orders, invoices, corporate quotes | <https://xlmindstudio.com/en/support?utm_source=github&utm_medium=referral&utm_campaign=github_public_repo&utm_content=support_md_page> |

## What to include in a bug report

The more of this you can give, the faster a problem gets resolved:

1. Your **XLMind Studio version**
2. Your **Windows version**
3. Your **Microsoft Excel version and architecture** (XLMind Studio requires 64-bit desktop Excel on Windows)
4. Which **tool** you were using, and on what kind of data
5. **What you expected** and **what happened instead**
6. **Steps to reproduce** the problem
7. A **screenshot** of the error, with any sensitive values removed

## Please never post these in a public issue

GitHub issues in this repository are public and permanently indexed. Do not include:

- License keys or activation codes
- Order numbers, invoices or payment details
- Email addresses or any other personal data
- Confidential, client or production workbooks
- Screenshots that show real customer, employee or financial records

If your question needs any of the above, use the [support page](https://xlmindstudio.com/en/support?utm_source=github&utm_medium=referral&utm_campaign=github_public_repo&utm_content=support_md_private) or email <support@xlmindstudio.com> instead. Support attachments are handled privately.
