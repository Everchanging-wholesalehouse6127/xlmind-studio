## What XLMind Studio does

XLMind Studio is a Windows desktop add-in for Microsoft Excel. It installs two ribbon tabs — **XLMind Data** and **XLMind Plus** — and turns the long, manual Excel work you repeat every week into single commands you run on a selected range or table.

The tasks that usually take an afternoon — untangling a messy export, checking two lists against each other, tracing where a broken formula comes from, rebuilding the same monthly report — are the tasks the product is built around.

## Feature categories

153 tools, organised into 17 groups across the two ribbon tabs.

### On the XLMind Data ribbon

| Group | What it gives you |
|---|---|
| **Quick** (2) | Everyday quick actions — undo the last XLMind operation, auto-fit a range in one step. |
| **Clean** (8) | Turn a messy export into a usable table: trim, clean, fix broken characters, clean headers, delete blanks, unmerge and fill, fill blanks. |
| **Extract** (9) | Pull information out of text — extract by pattern, quick extract and split columns without writing formulas. |
| **Text & Numbers** (10) | Reshape text and repair numbers: change case, prefix and suffix, remove in-cell duplicates, text to numbers, apostrophe numbers, leading zeros, formulas to values. |
| **Date** (5) | Repair dates that arrived as text, check date columns for problems and build new date values. |
| **Codes & Output** (3) | Mask sensitive columns, write numbers as words and colour alternating rows. |
| **Practical** (7) | Daily helpers — image validation, barcode and QR code creation and other small time savers. |

### On the XLMind Plus ribbon

| Group | What it gives you |
|---|---|
| **Combine & Get** (4) | Append worksheets, append selected tables, look up from another table and run multi-column lookups. |
| **Summarize & Prepare** (3) | Group by, unpivot columns and split data to get a table ready for reporting. |
| **Compare & Check** (6) | Compare two lists, compare rows, highlight duplicates and unique values, extract a unique list, add duplicate counts. |
| **Data Profile** (1) | One page that shows the health and structure of your table before you build anything on top of it. |
| **Formula Audit** (24) | The deepest group in the product: highlight formula cells, error cells and external-link formulas, build a formula map summary and run advanced audits. |
| **Color Tools** (2) | Count and sum by cell colour. |
| **Dashboards & Reports** (14) | Build a panel from ready-made Executive, Sales, HR and Finance layouts. |
| **KPI Cards** (13) | Live cards that show a single metric at a glance and refresh with the data behind them. |
| **Charts** (27) | Data-bound chart types that stay live instead of being pasted pictures. |
| **Maps** (15) | Geographic maps that shade regions by value. |

Every group, with the individual tools inside it, is listed on the [features page](https://xlmindstudio.com/en/features?utm_source=github&utm_medium=referral&utm_campaign=github_public_repo&utm_content=features) — and summarised in [docs/features.md](docs/features.md).

## Privacy: local-first by design

XLMind Studio runs on your computer, as part of Excel.

- Your Excel data stays on your computer for XLMind Studio's local processing.
- Workbook files, cell contents and worksheet names are not sent to XLMind Studio servers during normal product use.
- Excel content is not sent to or shared with artificial intelligence services.
- Internet access may be required for licensing and activation, payment, download, update checks, in-product information messages and support.

## Security and installer verification

The XLMind Studio installer is **digitally signed** with a code-signing certificate, and every release is published with a SHA-256 checksum so you can confirm that the file you downloaded is the file that was published.

Before you install, you can:

1. Download **only** from the official website — [xlmindstudio.com](https://xlmindstudio.com/en/download?utm_source=github&utm_medium=referral&utm_campaign=github_public_repo&utm_content=security_download).
2. Right-click the installer, open **Properties → Digital Signatures**, and check the publisher name.
3. Compare the SHA-256 checksum of your download against the value published on the security page.

The current version number, publisher details, certificate authority and SHA-256 value are maintained on the official security page rather than duplicated here, so that they are always current:

- English: <https://xlmindstudio.com/en/security>
- Türkçe: <https://xlmindstudio.com/tr/guvenlik>

See [SECURITY.md](SECURITY.md) for how to report a security concern, and [docs/security.md](docs/security.md) for the verification walkthrough.

> **Installer distribution.** XLMind Studio installers are **not** distributed through GitHub Releases. The official website is the only canonical download source.
